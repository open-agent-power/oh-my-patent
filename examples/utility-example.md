# 权利要求书

1. 一种带防滑结构的保温水杯，包括杯体与杯盖，所述杯盖可拆卸地连接于所述杯体的上端，其特征在于，所述杯体的外周面设有沿周向分布的若干条防滑凸筋，所述防滑凸筋自所述杯体的上端延伸至所述杯体的下端，且各条所述防滑凸筋的横截面均呈半圆形。

2. 根据权利要求1所述的带防滑结构的保温水杯，其特征在于，所述杯体的下端设有环形底座，所述环形底座的外径大于所述杯体的外径。

3. 根据权利要求2所述的带防滑结构的保温水杯，其特征在于，所述环形底座的下表面设有环形凹槽，所述环形凹槽内嵌设有硅胶密封圈。

4. 根据权利要求1所述的带防滑结构的保温水杯，其特征在于，所述杯盖的外周面设有沿周向延伸的防滑纹路。

# 说明书

## 技术领域

本实用新型涉及日常生活用品技术领域，具体涉及一种带防滑结构的保温水杯。

## 背景技术

现有的保温水杯大多采用不锈钢内胆与塑料外壳的结构，杯身表面普遍为光滑的圆柱面。使用时，如果使用者手部有水或油脂，光滑的杯身很容易从手中滑脱，导致水杯摔落、内胆破损或者热水溅出。

部分产品通过在杯身外套一圈硅胶套来解决防滑问题，但硅胶套与杯体之间容易积存水分，长期使用后会产生霉变，而且硅胶套在反复拆装后容易松脱。

## 发明内容

### 要解决的技术问题

本实用新型要解决的技术问题是：现有保温水杯的杯身表面光滑、握持时容易滑脱，而外加硅胶套的方案存在积存水分、容易松脱的问题。

### 技术方案

为解决上述技术问题，本实用新型提供一种带防滑结构的保温水杯，包括杯体与杯盖，杯盖可拆卸地连接于杯体的上端，杯体的外周面设有沿周向分布的若干条防滑凸筋，各条防滑凸筋自杯体的上端延伸至杯体的下端，且各条防滑凸筋的横截面均呈半圆形。

进一步地，杯体的下端设有环形底座，环形底座的外径大于杯体的外径。

进一步地，环形底座的下表面设有环形凹槽，环形凹槽内嵌设有硅胶密封圈。

进一步地，杯盖的外周面设有沿周向延伸的防滑纹路。

### 有益效果

本实用新型的有益效果是：通过在杯体外周面直接成型若干条半圆形截面的防滑凸筋，增大了手指与杯体之间的摩擦，同时凸筋之间形成纵向导流通道，手指上或杯壁上的水可以沿通道流下，不会积存在杯体与任何附加套件之间，从根本上避免了现有硅胶套方案积存水分、容易霉变的问题。由于防滑结构直接成型于杯体，也不存在套件松脱的风险。

## 具体实施方式

以下结合附图对本实用新型的具体实施方式作进一步说明。应当理解，此处所描述的具体实施例仅用以解释本实用新型，并不用于限定本实用新型。

参照图1，本实施例提供的带防滑结构的保温水杯包括杯体1与杯盖2。杯体1采用双层不锈钢结构，内胆与外壳之间为真空层，以降低热传导。杯盖2通过螺纹可拆卸地连接于杯体1的上端，杯盖2与杯体1的接合处设有食品级硅胶密封垫。

杯体1的外周面设有八条防滑凸筋3，八条防滑凸筋3沿杯体1的周向均匀分布，相邻两条之间的圆心角为四十五度。各条防滑凸筋3自杯体1的上端延伸至杯体1的下端，与杯体1一体成型。各条防滑凸筋3的横截面均呈半圆形，半圆形的半径取二毫米。

由于防滑凸筋3沿纵向延伸，相邻两条防滑凸筋3与杯体1的外周面之间形成纵向延伸的导流通道。当使用者手部有水时，水分沿导流通道向杯体1的下端流动，不会在杯体1表面形成连续的水膜，从而保持握持时的摩擦力。同时，纵向延伸的凸筋相对于横向环形凸筋更便于手指沿杯体1表面滑动调整握持位置。

参照图2，杯体1的下端设有环形底座4，环形底座4的外径大于杯体1的外径，使水杯放置在桌面上时的支撑面更大、重心更低，不易被碰倒。环形底座4的下表面设有环形凹槽5，环形凹槽5内嵌设有硅胶密封圈6。硅胶密封圈6的下表面略低于环形底座4的下表面，从而在放置时形成弹性接触，既增加摩擦力防止水杯被轻易推动，又起到缓冲作用，避免杯体与桌面直接硬碰。

杯盖2的外周面设有沿周向延伸的防滑纹路7，便于旋开和旋紧杯盖2。

本领域技术人员应当理解，防滑凸筋3的数量与横截面尺寸不限于上述具体数值，可以根据杯体1的直径与使用者的握持习惯进行调整，只要其落入权利要求所限定的范围内即可。

# 摘要

本实用新型公开一种带防滑结构的保温水杯，涉及日常生活用品技术领域。该保温水杯包括杯体与杯盖，杯盖可拆卸地连接于杯体的上端，杯体的外周面设有沿周向分布的若干条防滑凸筋，各条防滑凸筋自杯体的上端延伸至杯体的下端且横截面呈半圆形。本实用新型通过在杯体上直接成型纵向防滑凸筋增大了握持摩擦力，凸筋之间形成纵向导流通道，使水分不会积存，克服了现有外加硅胶套方案容易积存水分、易霉变且容易松脱的缺陷。本实用新型主要用于日常饮水。
